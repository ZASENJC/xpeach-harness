# @xpeach/xph-client-ui

## Summary

Browser plugin mounting the generated `xpeach` Remote contribution and
registering an XPeach settings section that renders the signed-in profile and
the first page of API tokens.

## Known Limitations and Deferred Work

Spike scope: read-only rendering, English/Chinese dictionaries, no styling
tokens beyond the section shell.
